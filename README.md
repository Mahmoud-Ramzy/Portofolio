## Notable Achievement

### Hate Speech Detection in Arabic Tweets

Graduation Project (A+)

Designed and developed an NLP system capable of detecting hate speech in Arabic social media content.

Key contributions:

* Advanced Arabic text preprocessing
* Data augmentation techniques
* Ensemble architecture combining BiLSTM and BERT-based models
* Improved F1-score from 0.5280 to 0.5479

This project strengthened my expertise in machine learning, NLP pipelines, experimentation, and research-oriented development.
